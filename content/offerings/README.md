Every offering in this catalog follows the same [delivery framework](./framework.md), so a
reader always meets the same eight stages in the same order, anchored to the same countdown
to delivery day. An offering fills in only the stages it actually uses.

Browse the catalog below. Search by keyword, or narrow the results with the filters, and a
new offering appears here as soon as its folder is added. The listing is generated at build
time from the offering pages themselves, so it cannot drift from them.

<!-- offering-catalog -->

## Add an offering

Create a folder under `content/offerings/`, add a `README.md`, and the offering joins both
the navigation and the catalog above. [Authoring an offering](./authoring.md) describes the
front matter and the stage blocks; the [offering template](./offering-template/README.md) is
a ready-to-copy skeleton that the build validates on every run.
