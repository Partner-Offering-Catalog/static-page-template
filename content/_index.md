Use this repository as a Hugo starting point for static documentation that should stay close to the content layout of the consuming repository. Place Markdown files under `content/` and the left navigation will mirror that folder hierarchy automatically.

## What this template provides

- A sticky Microsoft-inspired header with source links and a light/dark theme toggle.
- A multi-level left navigation built from Hugo sections and pages.
- Clean cards, readable typography, breadcrumbs, and responsive layouts.
- A minimal configuration suitable for publishing with GitHub Pages.

## Content model

Create folders with `_index.md` files when you want a navigation group. Add regular Markdown files for individual pages. Use `weight` in front matter to control ordering.
